Processo de Decisão de Markov (MDP)

Um agente precisa tomar decisões sequenciais. O resultado de uma ação depende do estado em que o agente está e pode haver incerteza.

Nesta aula vamos construir, de forma interativa, os conceitos de MDP, recompensa, retorno e desconto — sempre seguindo a sequência:

experiência → observação → generalização → formalização matemática

Bloco 3 — Recompensa imediata é suficiente?

Se o agente recebe uma recompensa agora, isso é suficiente para dizer que uma ação foi boa?

Trajetória A

s₀ → s₁ → s₂ → s₃ +10

Trajetória B

s₀ → s₁ → s₂ → s₃ +1 +1 +1
Qual situação é melhor?

Uma medida baseada somente na recompensa imediata é insuficiente para avaliar decisões sequenciais — precisamos olhar para o retorno, o acúmulo das recompensas futuras.

Bloco 4 — Retorno

Depois de acumular as recompensas passo a passo, formalizamos:

RECOMPENSA ↓ um evento imediato RETORNO ↓ acúmulo das recompensas futuras
G₀ = 2 + (-1) + 5 = 6

De forma geral, o retorno a partir do instante t é a soma de todas as recompensas futuras:

Gt = Rt+1 + Rt+2 + Rt+3 + ...

Bloco 4 — Retorno: o problema do atraso

+1000 Ação A ────────────● s₁ → s₂ → s₃ → ... → s₁₀₀₀
+1000 Ação B ──● s₁ → s₂
Sem desconto, qual ação parece melhor?

Os retornos não descontados podem ser iguais (ambos somam 1000).

Mas intuitivamente as duas opções parecem realmente equivalentes?

Isso motiva o desconto de recompensas futuras: receber a mesma recompensa mais cedo deveria valer mais.

Bloco 5 — Retorno descontado: interação com γ

Gt = Rt+1 + γRt+2 + γ²Rt+3 + γ³Rt+4 + ...
recompensa t ───── t+1 ─── t+2 ─── t+3 ─── t+4 +1 +1 +1 +10
γ 0.90
G = 1 + 0.90×1 + 0.90²×1 + 0.90³×10
G = 12.421
recompensapeso
Rₜ₊₁1
Rₜ₊₂γ
Rₜ₊₃γ²
Rₜ₊₄γ³

As recompensas futuras perdem cada vez menos peso conforme γ se aproxima de 1.

Bloco 6 — Retorno: formulação recursiva

Depois de entender o retorno como soma descontada, vamos derivar a sua forma recursiva passo a passo.

Gt = Rt+1 + γRt+2 + γ²Rt+3 + γ³Rt+4 + ...
O que está dentro dos parênteses, se destacarmos tudo depois de Rt+1?
Gt = Rt+1 + γ(Rt+2 + γRt+3 + γ²Rt+4 + ...)
Gt+1 = Rt+2 + γRt+3 + γ²Rt+4 + ...

Portanto:

Gt = Rt+1 + γGt+1
